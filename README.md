# rahinic.github.io

Hobby data portfolio, served by GitHub Pages. Plain static HTML and one stylesheet, no build step.

The net worth project is an illustrative simulation using synthetic data. It is not financial advice. The kitchen grimoire (recipes) lives in its own repo and is linked from the home page.

## Layout

- `index.html` – home
- `net-worth/` – net worth engine project pages
- `assets/` – shared stylesheet and favicon
